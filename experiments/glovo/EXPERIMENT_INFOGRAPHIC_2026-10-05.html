Difficulties encountered

Measurement

  • Time runs from agent start to completion. Parent tab preparation and adapter injection occurred before timing.
  • Tokens are cumulative agent usage. Uncached input + output excludes cached input; reasoning is already included in output.
  • Browser-call counts cover native browser invocations. One adapter agent’s completion message is included in its runtime/tokens, but not in its browser-call count.
  • Two agents per condition, fixed order and the same signed-in browser. The 3.59× result is an observed comparison, not a guaranteed multiplier.
